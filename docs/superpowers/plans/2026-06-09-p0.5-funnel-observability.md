**Goal:** Make the PB→TB→GB→~thousands-of-candidates **funnel** explicit + computed (the spec §3.2 hero narrative); surface per-asset **scale + provenance** metadata; add **OTel** observability (per-request requestID, cost/token, retrieval-path spans — TRANSPARENT pillar) with a **local in-memory span collector** for tests and Langfuse Cloud as a creds-gated export; and a **durable malformed-row audit sink** (the chunk_source drops, today only logged, become queryable records).

**Architecture (3 fairly independent modules — real parallelism):**
- `funnel/` — `FunnelTrace` records the stage-by-stage candidate-set collapse for ONE query: `(stage, count, bytes, note)` rows from `reduce/tier/dedupe → indexable-derivative → vectors → coarse → rerank → final_top_k`. Real counts/bytes for the indexable path; **stated** scale + provenance for the PB tail (BigQuery/Common Crawl) via catalog scale metadata. Asserts **monotonic non-increasing** reduction.
- `observability/` — `Tracer` over OpenTelemetry: per-request `request_id`, spans for route/retrieve/rerank/govern/generate, attributes for cost/token. An `InMemorySpanCollector` (no creds) is the test target; `LangfuseExporter` (creds-gated) is the live export. **No API call in the hot path that can't be faked.**
- `governance/audit_sink.py` — a durable `AuditSink` for governance events incl. the malformed-row drops from `chunk_source` (today `logging.warning` only). In-memory sink for tests; a `SurrealAuditSink` (SurrealDB `audit` table) for durability. `chunk_source` calls the sink so dropped-governance-row events are queryable, not just logged.

Plus a small `CatalogAsset` extension: surface `scale_badge` + `provenance_url` + `row_count` onto the catalog asset (from the manifest, via the connector) so the funnel + a future Sources UI can read them.

```python
def test_funnel_is_monotonic_non_increasing():
    from rag_engine.funnel.trace import FunnelTrace
    t = FunnelTrace()
    t.stage("raw_tail", count=None, bytes=1_000_000_000_000_000, note="PB (stated, BigQuery)")
    t.stage("indexable_derivative", count=50_000, bytes=19_000_000)
    t.stage("structured_prefilter", count=4_000)
    t.stage("coarse_ann", count=200)
    t.stage("rerank", count=8)
    t.stage("final_top_k", count=5)
    counts = [s.count for s in t.stages if s.count is not None]
    assert counts == sorted(counts, reverse=True)   # monotonic non-increasing
    assert t.reduction_factor() > 1
```

`compute_funnel(catalog, query_candidates)` builds a trace from a real candidate collapse + the catalog's stated PB-tail scale. Commit.
