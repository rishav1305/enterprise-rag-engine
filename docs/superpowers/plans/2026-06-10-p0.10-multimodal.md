## Headline governance invariant (fail-closed — the multimodal leak oracle)
**A non-text chunk (image / table / OCR'd-doc / figure) carries a full `SecurityContext` and is governed by the SAME pipeline as text.** Three sub-invariants, each hardened + mutation-proven:

1. **Same pre-filter** — a denied image/table/figure chunk NEVER surfaces in any retrieval mode (identical allowlist pre-filter; the allowlist is modality-agnostic — it keys on chunk_id + ACLs).
2. **Masking for non-text = WITHHOLD** — you can't `[REDACTED]` a pixel inline, so a `mask`/`partial` non-text chunk has its **raw payload withheld entirely**: `content` → redaction token AND the binary payload stripped from `metadata` (so the model/citations never see raw bytes). The current `redact_chunk` copies `metadata` verbatim → it would LEAK a payload stored there; this phase closes that. Contract: withhold (payload removed) + a placeholder token; never serve raw.
3. **OCR/extraction inherits source classification** — text extracted from a scanned class-F PDF is class-F, not public. No declassification-by-extraction: the extracted chunk's `SecurityContext` is the SOURCE document's, never a fresh/default one.

**Headline test:** a masked image + masked table + OCR chunk → an under-cleared session gets withheld/redacted (token in content, NO raw payload in metadata), never the raw payload; across modalities. **Mutation:** skip the multimodal payload-strip in redaction → raw image/table bytes surface in metadata → fails. Treat like the leak oracle.

## Design — modality is a tag; payload lives behind a redactable seam
`EnrichedChunk` gains a `modality` field (text|image|table|ocr|figure, default "text" — back-compat). The binary/structured payload lives in `metadata` under a single conventional key (`MULTIMODAL_PAYLOAD_KEY`), so redaction has ONE place to strip. Extractors produce chunks with `modality` + `SecurityContext` (inherited from the source). The allowlist + per-mode pre-filter are already modality-agnostic (chunk_id + ACLs) — so sub-invariant 1 is automatically satisfied; the test pins it. The work is (2) extend `redact_chunk` to withhold non-text payloads, and (3) make extraction inherit classification.
