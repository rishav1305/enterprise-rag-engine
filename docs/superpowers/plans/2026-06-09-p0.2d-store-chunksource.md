# P0.2d — SurrealStore → ChunkSource adapter (production wiring)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Make the live vector path hydrate + derive its allowlist from the **real SurrealDB store** (not in-memory doubles): implement the `ChunkSource` protocol over `SurrealStore`, prove the C1-over-vector enforcement end-to-end against a real SurrealDB instance, and fix the ELASTIC O(N) allowlist scan to project ids+ACLs only (no full content/vector pulls per query).

**Architecture:** A `SurrealChunkSource(store)` satisfies the P0.2c `ChunkSource` Protocol:
- `get_chunk(chunk_id) -> EnrichedChunk | None` — `SELECT * FROM chunk:<id>`; rebuild the `EnrichedChunk` (text + `SecurityContext` from `cls`/`level` via the shared `_CLASS_ROLES`/`_CLASS_LEVEL` — DRY, no drift).
- `all_chunk_security() -> list[EnrichedChunk]` — **projects `id, asset_id, cls, level` only** (NOT `text`/`vec`) so the allowlist pass doesn't drag full content/vectors per query (the ELASTIC fix). Returns lightweight `EnrichedChunk`s (empty content) carrying just the id + `SecurityContext` for `authorized_chunk_ids`.

`TurboVecRetriever` is unchanged — it already takes any `ChunkSource`. P0.2d just provides the real one + proves it. The in-memory unit tests stay (fast, deterministic); the new store-backed E2E proves production wiring.

**Tech Stack:** `SurrealStore` (P0.2a/b), the `ChunkSource` Protocol + `TurboVecRetriever` (P0.2c), the shared `_CLASS_ROLES`/`_CLASS_LEVEL` (catalog/connector), `TurboVecIndex` + `build_index` (P0.2b), the surreal_local fixture.

## ELASTIC note (the O(N) fix, scoped)
`authorized_chunk_ids` is O(N) — it evaluates every chunk's ACL per query. P0.2d gets it **off "pull every chunk's content/vector per query"**: `all_chunk_security()` projects ids+ACLs only (SurrealQL `SELECT id, asset_id, cls, level FROM chunk`). Full ReBAC list-objects (Oso/SpiceDB) to make it sub-linear stays a later phase (tracked); this phase removes the content/vector-blob cost.
