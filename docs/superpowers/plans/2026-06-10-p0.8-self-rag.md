## Headline governance invariant (fail-closed — the P0.8 leak oracle)
**The corrective/agentic loop must NEVER become a permission-escalation path.** Every re-retrieval — reformulated query, mode fallback, scope broadening — MUST go through the SAME permission pre-filter / `authorized_chunk_ids`. The grader and every loop iteration only EVER see authorized content. A reformulated query cannot widen the allowlist; "re-retrieve broader" is still session-scoped.

**Headline hardened test:** an under-cleared session whose first retrieval is graded "insufficient" triggers corrective re-retrieval → across ALL iterations the loop never surfaces a denied chunk (assert over every iteration, not just the first).
**Mutation (the bite):** a corrective step that re-retrieves WITHOUT the session pre-filter → the denied-content test fails. Treat like the leak oracle.

## Design — the loop is a thin orchestrator over EXISTING session-scoped retrieval
The loop NEVER retrieves directly. It calls a `retrieve_fn(query, session) -> list[ScoredChunk]` injected by the caller — in production that is `TurboVecRetriever.retrieve_for_session` (already allowlist-pre-filtered + mandatory rerank) or the P0.6 mode retrievers. The loop reformulates the *query text* only; the *session* is fixed and threaded unchanged into every `retrieve_fn` call. There is structurally no path for the loop to pass a different/empty allowlist — it doesn't construct allowlists at all. This is how the invariant is guaranteed, and the headline test pins it.

## Spine (serial, single-writer) — Tasks 0–2
- **T0 — grader contracts (`selfrag/grader.py`).** `RelevanceGrade` (per-chunk or set-level: sufficient|insufficient + score + reason) and `GroundednessGrade` (grounded|ungrounded + score + unsupported_spans). `Grader` Protocol: `grade_relevance(query, chunks) -> RelevanceGrade`; `grade_groundedness(query, answer, chunks) -> GroundednessGrade`. `FakeGrader` (deterministic, rule-driven for tests — e.g. relevance = keyword overlap threshold; groundedness = answer tokens ⊆ context tokens). SPINE.
- **T1 — loop config (`config.py`).** `selfrag_enabled`, `selfrag_max_iterations` (bounded — RESILIENT), `selfrag_relevance_threshold`, `selfrag_groundedness_threshold`, `selfrag_grader` (fake|openai). Env-driven + `__post_init__` validation (CONFIGURABLE; reuse the P0.7 validator pattern). SPINE.
- **T2 — `CorrectiveLoop` orchestrator (`selfrag/loop.py`).** Bounded `retrieve → grade_relevance → (reformulate + re-retrieve | abstain) → generate → grade_groundedness → (refine | abstain | return)`. Takes injected `retrieve_fn(query, session)`, `generator`, `grader`, `query_reformulator`. **Retry budget + grader circuit breaker** (grader raises/trips → degrade: stop looping, return best-so-far or abstain — never hang). **Abstain fail-closed**: budget exhausted without a grounded answer → `LoopResult(abstained=True, ...)`, no fabrication. Threads `session` unchanged into every `retrieve_fn` call. SPINE.

## Workers (parallel, disjoint files) — flag fan-out
- **WORKER-A — governance-preserving headline (`tests/test_selfrag_governance.py`).** The leak oracle: under-cleared session, first retrieval graded insufficient → corrective re-retrieve → assert NO denied chunk in ANY iteration's candidate set (a `recording_retrieve_fn` captures every call's session + output; assert every call used the same session and a denied-content probe never appears). Mutation-documented: a bypass `retrieve_fn` ignoring session → fails. Also: reformulation can't widen the allowlist (the loop only changes query text).
- **WORKER-B — corrective grading mechanics (`tests/test_selfrag_grading.py`).** Relevance grade drives corrective action (insufficient → re-retrieve; sufficient → generate); groundedness grade drives refine/abstain; `FakeGrader` determinism. Abstain-not-fabricate when retrieval stays poor.
- **WORKER-C — bounded loop + RESILIENT (`tests/test_selfrag_loop.py`).** Iteration cap enforced (no infinite loop even if grader always says "insufficient"); retry budget; **grader circuit breaker** (grader raises → graceful degrade, returns/abstains, doesn't hang or crash the request); each iteration emits a tracing span + funnel note (TRANSPARENT — steps + stop reason); the provenance/`LoopResult` shows WHY it stopped (grounded | budget-exhausted-abstain | grader-degraded).
- **WORKER-D — live LLM grader (`selfrag/openai_grader.py` + `tests/test_selfrag_openai_grader.py`).** `OpenAICompatGrader` (Groq/NVIDIA, mirrors `OpenAICompatGenerator`); creds-gated (`@pytest.mark.llm`). The fake grader is always tested; the live grader's prompt/parse is unit-tested with a stubbed client where cheap, live path gated.
