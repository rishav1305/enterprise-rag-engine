# P0.2c — Retrieval Integration (TurboVec live + allowlist enforcement)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Turn the P0.2b "built, not wired" pieces into LIVE enforcement — wire `TurboVecIndex` into the retriever for vector mode (vectors-by-id from the SurrealDB store), apply the **allowlist permission pre-filter at the index per session**, make the **reranker mandatory** on the TurboVec coarse set (the load-bearing finding), and prove it end-to-end: a class-D chunk retrieved via the live TurboVec path is `[REDACTED]` in answer + citations, raw PII never present.

**Architecture:** A new `TurboVecRetriever` (implements a session-aware retrieve) wraps a loaded `TurboVecIndex` (the ANN) + a `SurrealStore`/in-memory chunk source (text + ACLs by id). Its `retrieve_for_session(query, session)`:
1. derive the **allowlist** = chunk ids this session may see (`governance.allowlist.authorized_chunk_ids` over the catalog/chunks);
2. embed the query, `TurboVecIndex.search(q, coarse_k, allowlist_chunk_ids=allow)` → coarse candidates (unauthorized vectors never returned — pre-filter at the index);
3. fetch chunk text+ACLs for the returned ids from the store;
4. **always rerank** the coarse set (config cannot disable rerank on the vector path);
5. hand the reranked `ScoredChunk`s to the existing L5 `SecurityFilter` (C1 masking) → generation. Pre-filter + post-filter compose (defense in depth): the allowlist drops *denied* before search; the post-filter *masks* mask/partial and is the second gate.

The existing permission-blind `HybridRetriever.retrieve(query)` stays (the leak demo's "retrieval is permission-blind" story holds for the lexical/in-memory path). P0.2c adds the **vector-mode session-aware path** alongside it; the router selects it for vector queries.

**Tech Stack:** `TurboVecIndex` + `IdMap` (P0.2b), `governance.allowlist` (P0.2b), `SurrealStore` (P0.2a), the existing `Reranker`/`SecurityFilter`/`build_citations`/`ExtractiveGenerator`, `HashingEmbedder` (deterministic CI; Voyage swappable).

```python
class ChunkSource(Protocol):
    def get_chunk(self, chunk_id: str) -> EnrichedChunk | None: ...
    def all_chunk_security(self) -> list[EnrichedChunk]: ...  # id+security only, for allowlist

class TurboVecRetriever:
    def __init__(self, index: TurboVecIndex, embedder: Embedder,
                 source: ChunkSource, reranker: Reranker,
                 config: EngineConfig | None = None) -> None: ...
    def retrieve_for_session(self, query: str, session: Session) -> list[ScoredChunk]:
        """allowlist pre-filter at index -> coarse -> MANDATORY rerank -> top_k.
        Returns store-hydrated ScoredChunks (full text+ACLs); never returns a
        chunk whose id is not in the session allowlist."""
```
