# P0.2b — TurboVec Vector Index + Allowlist Permission Pre-filter

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Stand up TurboVec as the compressed vector ANN index whose external ids round-trip to the SurrealDB store (P0.2a), with **allowlist filtered search enforcing permissions as a PRE-filter at the index** (the at-scale evolution of the post-filter) — and **re-validate recall on REAL embeddings** (S1's caveat: it used random vectors).

**Architecture:** A `TurboVecIndex` (built on `turbovec.IdMapIndex`, bit_width=4, S1-validated) holds chunk vectors keyed by `uint64` ids that map to SurrealDB chunk record ids. An offline build step embeds the Wikipedia-KB-derivative chunks (real deterministic embeddings — a seeded hashing embedder for CI determinism, with the Voyage adapter as the swappable production path) and writes `index.tvim`. At query time the router's vector mode: derive the **allowlist** (the chunk ids a session is cleared for, from the catalog/governance) → `IdMapIndex.search(query_vec, k, allowlist=...)` → only authorized vectors are even *candidates* (permission PRE-filter at the index) → results' ids fetch chunk text + ACLs from SurrealDB → the existing post-filter/masking (C1) still runs as defense-in-depth. TurboVec owns ANN; SurrealDB holds vectors-by-id + metadata (per S2).

**Tech Stack:** `turbovec==0.7.0` (`IdMapIndex`, abi3 wheel — serverless-loadable per S1), numpy, the P0.2a `SurrealStore`, the existing `Embedder` ABC + a deterministic `HashingEmbedder`, the leak-oracle spine.

> **S1 spike (`docs/spikes/s1-turbovec-serverless.md`):** KEEP. Cold-load <1s, fits Vercel RAM, `IdMapIndex.search(allowlist=uint64[])` pre-filter is correct + free. **Carried-forward caveat: recall measured on RANDOM vectors — re-validate on real embeddings here.**

## Task 6: Recall re-validation on REAL embeddings (the carried-forward caveat)

**Files:** Create `tests/test_turbovec_recall.py`

- [ ] **Step 1: Write the recall test** — use **clustered/structured** embeddings (real embeddings have cluster structure, unlike S1's random vectors). Either: (a) the deterministic `HashingEmbedder` over the Wikipedia-KB-derivative chunk texts, or (b) seeded clustered synthetic vectors (gaussian mixtures). Measure recall@10 of TurboVec (bit_width=4) vs exact cosine; assert it clears a threshold that's honest for a coarse stage feeding a reranker.

```python
def test_turbovec_recall_on_clustered_embeddings_meets_threshold():
    import numpy as np
    from rag_engine.retrieval.turbovec_index import TurboVecIndex
    # clustered (gaussian-mixture) vectors model real embedding structure
    rng = np.random.default_rng(7); dim=256; n=5000; nclus=50
    centers = rng.standard_normal((nclus, dim))
    labels = rng.integers(0, nclus, n)
    v = (centers[labels] + 0.15*rng.standard_normal((n,dim))).astype("float32")
    v /= np.linalg.norm(v, axis=1, keepdims=True)
    ids = [f"chunk:{i}" for i in range(n)]
    idx = TurboVecIndex(dim=dim, bit_width=4); idx.add(ids, v)
    # exact top-10 ground truth
    qn = 50
    sims = v[:qn] @ v.T
    gt = np.argsort(-sims, axis=1)[:, :10]
    hit=tot=0
    for i in range(qn):
        got = {int(h.chunk_id.split(':')[1]) for h in idx.search(v[i], k=10)}
        hit += len(got & set(gt[i].tolist())); tot += 10
    recall = hit/tot
    assert recall >= 0.85, f"recall@10={recall:.3f} below coarse-stage threshold"
```
