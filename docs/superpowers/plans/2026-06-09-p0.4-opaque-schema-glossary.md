# P0.4 — Opaque-schema semantic glossary (the differentiator)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Reverse-engineer the meaningless `legacy_mart` schema (`tbl_44`, `text_2`) into a governed semantic glossary, so the text-to-SQL agent retrieves over the **glossary** (not the raw schema): a NL question about "customer name" resolves to `tbl_44.text_2` and the agent writes `SELECT text_2 FROM tbl_44` correctly — **with per-table semantics** (`tbl_44.text_2`=full_name PII-masked, `tbl_71.text_2`=order_status, not masked).

**Architecture (spec §3.3, S3 verdict = BUILD):** `enrichment/schema_glossary/`:
- `profiler.py` — value stats per physical column (regex/format class, cardinality, null rate, FK overlap) from the `legacy_mart` rows.
- `view_miner.py` — `sqlglot.lineage` over legacy VIEW/query-log SQL: `CREATE VIEW v_cust AS SELECT text_2 AS name FROM tbl_44` is **evidence** that `tbl_44.text_2` means "name". Per-table: `v_orders … text_2 AS status FROM tbl_71` ⇒ `tbl_71.text_2`=status.
- `drafter.py` — LLM-drafts a `{means, synonyms, examples}` per physical column via the `Generator`-ABC LLM (Groq/NVIDIA live; a **deterministic `FakeGlossaryDrafter`** for tests).
- `glossary.py` — the `GlossaryEntry` model `{physical, table, means, synonyms, examples, confidence, source, join_paths}` + a `Glossary` store (SurrealDB-backed via `SurrealStore`; an in-memory store for tests). Confidence: HIGH when view-mined, LOW when only LLM-drafted (until human-approved).
- `drift.py` — drift check: a new/renamed physical column not in the glossary (or a glossary entry whose column vanished) → flagged; a CI test fails on drift.
- `resolve.py` — `resolve(nl_term, table=None) -> (table, physical)`: NL "customer name" → `tbl_44.text_2`. The text-to-SQL agent uses this to write correct SQL over the opaque schema.

**🎯 HEADLINE:** wire the text-to-SQL agent to **retrieve over the glossary, never the raw schema** — proven by a test: NL "customer name" → glossary → `SELECT text_2 FROM tbl_44`, executed through `GuardedBigQuery`, with `tbl_44.text_2` masked (per-table) in the result.
