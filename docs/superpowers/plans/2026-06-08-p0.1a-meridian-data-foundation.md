## Determinism
Single `SEED` in `EngineConfig`. `_rng.derive_rng(source)` seeds from `hash(SEED, source)` so each source is independently reproducible and adding one never shifts another. No wall-clock, no `uuid4()`, no unseeded shuffles; timestamps from a fixed epoch + seeded offsets. Coherence anchors computed once in `_coherence.py` and shared.

## Risks / notes
- **Coherence ordering** is the only intra-phase serial dependency — Finance cluster (Agent E) runs after `_coherence.py`. Sequence E into a second fan-out batch.
- **SurrealDB write** in `emit.py` depends on a reachable SurrealDB (Cloud or titan-pc self-host). For P0.1a, `emit.py` writes to a **local SurrealDB / file target** behind the store interface so the phase is self-contained; the Cloud wiring is verified but the gate runs against local for reproducibility. (Multi-setup portability — both targets real.)
- **Telemetry @ ~200M lines** is generated as a streaming/parameterized generator (don't materialize 200M rows in CI — generate a representative slice + a documented full-volume mode for the funnel tier-out demo).
- BigQuery live pulls gated behind `-m live` to protect the sandbox quota (cost guard, SECURE pillar).
